# 운영정책 확인 기록

기획 판단의 근거를 남겨두는 문서. 정책은 바뀌므로 **확인한 날짜와 그때 본 내용**을 함께 적는다.

## 현재 상태 요약

기획 2판에서 확률 요소를 전부 제거했다. **현재 설계에는 확률형 콘텐츠도 도박 요소도 없다.** 아래 기록은 그 판단에 이르기까지의 경위다.

## 확인 기록

### 2026-08-31 (1판) — 도박 콘텐츠 금지 확인

**확인 내용.** 무료 게임 재화를 사용하더라도 도박 · 카지노 모사와 베팅 콘텐츠 자체가 금지된다. 슬롯머신과 빠칭코를 반복하는 구조는 금지 사례에 거의 직접 해당한다.

**출처.** 크리에이터 운영정책 (위 링크). 원문을 직접 확인한 것이 아니라 정리된 안내를 옮긴 것이므로, 출시 전 원문 재확인 필요.

**기획에 반영한 결정.** 빠칭코 · 슬롯머신 구상을 연금술 제작으로 전환. 도박 연상 표현을 사용하지 않기로 함.

### 2026-08-31 (1판) — 확률 공개 의무 확인

**확인 내용.** 확률형 콘텐츠 자체는 제공할 수 있으나, 사용 전에 정확한 확률을 표시해야 하고 고지한 확률과 실제 로직이 일치해야 한다. 유료 재화가 연결되면 추가 의무가 생길 수 있다.

**기획에 반영한 결정.** 연금술 확률표를 UI에 노출하고, 구현 후 코드의 확률값과 표시값을 대조해 검증하기로 함.

### 2026-08-31 (2판) — 확률 요소 제거로 규제 검토 불필요

**변경 내용.** 연금술 뽑기를 없애고 록맨식 보스 능력 획득으로 전환했다. 이로써 게임에 확률형 콘텐츠가 남지 않는다.

**정책상 의미.** 확률 표시 의무와 도박 콘텐츠 규제 모두 해당 사항이 없어졌다. 마력 구슬을 늘리는 수단도 확률이 아니라 자기 제약(능력 봉인, 노히트, 시간 제한)이라 결과가 운이 아닌 플레이어의 실력으로 결정된다.

**남는 주의사항.**

- 도박 · 카지노를 연상시키는 표현은 계속 쓰지 않는다 (슬롯 릴, BAR, 777, 카지노 칩, 베팅, 배당, 잭팟)
- 나중에 확률 요소를 다시 넣게 되면 위 확률 공개 의무 항목을 다시 확인한다
