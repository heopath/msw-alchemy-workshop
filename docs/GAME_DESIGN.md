# 몬스터 연금술 공방 (가칭)

> 상태: 기획 초안 · 최종 수정 2026-08-31

## 한 줄 요약

몬스터를 사냥해 모은 마력 구슬을 연금술로 장비와 보스 입장권으로 바꾸고, 그 장비로 보스에 도전하는 짧은 순환형 게임.

## 게임 루프

```
사냥 (3~5분)  →  마력 구슬 획득  →  연금술 제작  →  보스전 (2~3분)  →  다시 사냥
```

한 바퀴가 10분 안쪽이라 짧게 치고 빠지는 플레이에 맞다. 각 단계가 다음 단계의 준비가 되므로 "한 번만 더" 감정이 자연스럽게 이어진다.

1. 필드에서 3~5분간 몬스터를 사냥한다
2. 몬스터가 마력 구슬을 떨어뜨린다
3. 마력 구슬을 연금술 장치에 넣어 무기 조각 · 보스 입장권 · 버프를 제작한다
4. 플레이어가 원하는 보상 계열을 먼저 선택한다
5. 장비를 갖춘 뒤 2~3분짜리 보스전에 도전한다
6. 계속 파밍하거나 연금술을 반복한다

## 설계 제약 — 왜 연금술인가

원래 구상은 빠칭코 · 슬롯머신이었으나 **도박 · 카지노 모사와 베팅 콘텐츠는 메이플스토리 월드 크리에이터 운영정책상 금지**되어 있다. 특히 슬롯머신을 반복하는 구조는 금지 사례에 거의 직접 해당한다.

그래서 **감정은 유지하고 외형과 규칙만 바꿨다.** 옮기려는 감정은 다음 네 가지다.

- 수집 — 구슬이 쌓이는 재미
- 기대감 — 이번엔 좋은 게 나올까
- 큰 성공 — 드물게 터지는 희귀 결과
- 한 번 더 — 다시 시도하게 만드는 힘

정체성을 카지노가 아니라 **사냥과 제작**에 둔다. 자세한 근거와 확인 기록은 [POLICY_NOTES.md](POLICY_NOTES.md) 참고.

### 사용하지 않는 표현

슬롯 릴, BAR, 777, 카지노 칩, 베팅, 배당, 잭팟 등 도박을 연상시키는 시각 요소와 용어는 쓰지 않는다.

## 연금술 규칙

확률형 요소는 두되, 도박이 아닌 제작으로 읽히게 만드는 장치들이다.

| 규칙 | 의도 |
|---|---|
| 꽝 없이 최소 보상 보장 | 투입이 항상 결과로 이어짐 |
| 10회마다 희귀 결과 확정 | 운에만 기대지 않게 함 |
| 결과 계열 선택 (무기 / 방어 / 입장권) | 플레이어가 목표를 정함 |
| 중복 아이템 자동 재료 전환 | 낭비되는 결과가 없음 |
| 타이밍 입력 보너스 | 조작 개입 여지를 둠 |

마지막 항목이 특히 중요하다. 순수 확률이 아니라 플레이어의 입력이 결과에 영향을 주면 도박보다 제작 미니게임에 가까워진다.

## 확률표 (초안)

구슬 5개 투입 기준.

| 결과 | 확률 |
|---|---|
| 일반 무기 조각 | 60% |
| 고급 무기 조각 | 25% |
| 보스 입장권 조각 | 10% |
| 희귀 보스 무기 조각 | 5% |

**확률형 콘텐츠는 사용 전에 정확한 확률을 표시해야 하고, 표시한 값과 실제 로직이 일치해야 한다.** 유료 재화가 연결되면 추가 의무가 생길 수 있다. 이 표는 UI에 그대로 노출하고, 구현 시 코드의 확률값과 대조해 검증한다.

## 프로토타입 범위

첫 버전은 여기까지만 만든다.

- 필드 1개
- 몬스터 3종
- 연금술 결과 6종
- 보스 1마리

루프가 재미있는지 확인하는 게 목적이므로 콘텐츠 양을 늘리지 않는다.
