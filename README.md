# 메이플 마스터즈 (가칭)

메이플스토리 월드로 만드는 로그라이크 액션. 옛날 메이플 지역을 원하는 순서로 골라 돌며, 보스를 잡으면 그 지역의 능력을 얻는다. 그 능력이 다른 보스의 약점이 된다.

```
지역 선택  →  스테이지 돌파  →  보스전  →  능력 획득  →  다음 지역 선택
                                                             ↓
                         죽음  →  능력 초기화, 구슬과 지식은 남음
```

죽으면 능력은 잃지만 **순서를 알아낸 지식**은 플레이어에게 남는다. 두 번째 판이 빨라지는 이유는 캐릭터가 세져서가 아니라 내가 순서를 알기 때문이다.

## 지역

헤네시스 · 엘리니아 · 페리온 · 커닝시티 · 리스항구를 어떤 순서로든 도전할 수 있고, 다섯 곳을 모두 클리어하면 슬리피우드가 열린다.

## 개발 환경

메이플스토리 월드 메이커의 로컬 워크스페이스를 사용하며, Claude Code를 MCP로 연결해 작업한다.

`.mcp.json`에는 API 키가 평문으로 들어가므로 저장소에 올리지 않는다. 형식은 [.mcp.json.example](.mcp.json.example) 참고. 메이커의 `AI Lab → AI ToolKit Settings`에서 연결하면 각자 생성된다.
