# 몬스터 연금술 공방 (가칭)

메이플스토리 월드로 만드는 짧은 순환형 게임. 사냥으로 모은 마력 구슬을 연금술로 장비와 보스 입장권으로 바꾸고, 그 장비로 보스에 도전한다.

```
사냥 (3~5분)  →  마력 구슬 획득  →  연금술 제작  →  보스전 (2~3분)  →  다시 사냥
```

## 문서

- [기획서](docs/GAME_DESIGN.md) — 게임 루프, 연금술 규칙, 확률표, 프로토타입 범위
- [운영정책 확인 기록](docs/POLICY_NOTES.md) — 설계 판단의 근거

## 설계 메모

원래 구상은 빠칭코였으나, 도박·카지노 모사 콘텐츠가 크리에이터 운영정책상 금지되어 있어 연금술 제작으로 전환했다. 수집·기대감·큰 성공·한 번 더라는 감정은 유지하고 외형과 규칙만 바꿨다. 자세한 내용은 위 두 문서에 있다.

## 개발 환경

메이플스토리 월드 메이커의 로컬 워크스페이스를 사용하며, Claude Code를 MCP로 연결해 작업한다.

`.mcp.json`에는 API 키가 평문으로 들어가므로 저장소에 올리지 않는다. 형식은 [.mcp.json.example](.mcp.json.example) 참고. 메이커의 `AI Lab → AI ToolKit Settings`에서 연결하면 각자 생성된다.
